By now you should have a certain amount of services already running as a part of Happy Headlines.

This week you are going to create a pipeline for all these services to automatically build and deliver them everytime something new arrives on the master/main-branch on GitHub.

You decide if you want to use GitHub Actions or any similar tool to meet this requirement. For the continuous delivery part you are expected to store the Docker Images with a version number in a central repository somewhere (for instance the GitHub Container Registry, but any similar tool will work).
